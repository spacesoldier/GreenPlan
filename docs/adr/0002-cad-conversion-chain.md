# ADR-0002: ODA публикует DXF, LibreDWG служит независимой диагностикой

- Status: Accepted
- Date: 2026-09-25
- Owners: CAD ingestion
- Related phase: Phase 1
- Supersedes: —
- Superseded by: —

## Context

В наборе присутствуют DWG семейства AutoCAD 2018–2025, вложенные архивы и нестандартные объекты. Нужен массовый Linux-конвейер с диагностикой потерь. LibreDWG способен читать большую часть файлов, но его предупреждения и неполная поддержка классов не позволяют считать его единственным издателем результата.

## Decision

- ODA File Converter является primary converter и единственным источником публикуемого DXF.
- LibreDWG запускается независимо как reader/diagnostic stage и не перезаписывает ODA-результат.
- Успех стадий хранится раздельно; warning LibreDWG не превращает успешный ODA DXF в failure.
- Публикация атомарна, сохраняет относительный путь после корня проекта и проверяет SHA-256.
- Исходные DWG неизменяемы; рабочая папка job не является выдачей.

## Alternatives considered

### Только LibreDWG

Отклонено из-за ошибок/неполного JSON на части R2018-файлов и диагностических сообщений о неподдержанных объектах.

### Только ODA без независимого reader

Отклонено: факт успешной конвертации не показывает неожиданные классы и расхождения чтения.

### AutoCAD automation

Не подходит для воспроизводимого Linux/Docker-контура и требует отдельной проприетарной среды.

## Consequences

### Positive

- все 819 обычных и 432 архивных DWG получили DXF AC1032;
- диагностика не блокирует выдачу, но сохраняет сигналы для fidelity-review;
- конвертер можно заменить за границей worker stage.

### Negative / trade-offs

- ODA имеет отдельные условия лицензирования и устанавливается пользователем;
- два reader увеличивают время и объём логов;
- semantic fidelity всё равно требует последующего анализа DXF.

## Verification

- проверка DWG-сигнатуры до постановки в очередь;
- exit code и наличие непустого DXF;
- `$ACADVER = AC1032`;
- SHA-256 публикации;
- раздельные stage statuses и сохранённый stderr;
- выборочный/рисковый entity-layer diff.
