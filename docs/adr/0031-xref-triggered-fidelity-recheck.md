# ADR-0031 — Повторное сравнение DWG/DXF после разрешения XREF

- Status: Accepted
- Date: 2026-09-28
- Owners: CAD ingestion, fidelity control, frontend

## Context

Проверка XREF и проверка полноты преобразования DWG в DXF раньше завершались независимо.
После ручного выбора внешних ссылок создавался только этап `xref_resolution`, а предупреждение
`independent_pre_inventory_incomplete` сохраняло первоначальный текст. Инженер не мог понять,
учтено ли разрешение зависимостей в актуальном fidelity-результате.

Кроме того, file-scoped завершение ошибочно ожидало закрытия всех findings файла, включая само
fidelity-предупреждение. Это создавало циклическую блокировку повторной проверки.

## Decision

После закрытия всех открытых findings с кодом `xref_*` для исходного чертежа API автоматически:

1. фиксирует этап `xref_resolution`;
2. запускает этап `fidelity_recheck` для того же `source_asset_id`;
3. заново читает сохранённые source и converted DXF inventories;
4. сравнивает только метрики, независимо присутствующие с обеих сторон;
5. добавляет количество разрешённых и оставшихся XREF в evidence;
6. закрывает прежнее предупреждение только при доказанном совпадении доступных метрик и отсутствии
   неразрешённых связей; иначе обновляет его актуальным результатом повторной проверки.

Ручной waiver XREF помечает соответствующее ребро `ignored`. Это не выдаётся за найденный файл:
состояние и метод `revision_waiver` сохраняются отдельно.

Сравнение не должно объявлять документы равными, если исходный DWG reader не предоставил ни одной
общей числовой метрики. В таком случае recheck завершается как `completed_with_warnings`.

## Consequences

- разрешение XREF наблюдаемо влияет на fidelity pipeline;
- предупреждение содержит результат последней проверки, а не первоначального запуска;
- неполные данные LibreDWG по-прежнему честно дают `not comparable`;
- будущий полноценный DWG reader сможет использовать тот же контракт метрик без изменения UI.

## Verification

- unit test проверяет совпадающие поля и расхождения;
- unit test запрещает положительный verdict без общих метрик;
- после последней XREF в журнале появляются `xref_resolution` и `fidelity_recheck`;
- waiver XREF сохраняет ребро как `ignored`;
- старое fidelity-предупреждение обновляется или закрывается, но не дублируется.
