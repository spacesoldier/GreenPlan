# Phase 4, iteration 3 — назначение классов semantic assistant

Статус: реализовано 2026-09-29.

Связанный ADR: [ADR-0039](../adr/0039-assistant-category-assignment-for-unclassified-layers.md).

## Цель

Убрать второе ручное действие после содержательной подсказки модели и не пересчитывать уже
назначенные классы.

## Контракты

1. Job scope содержит только слои с `mapping_status <> confirmed` выбранного файла.
2. Содержательный ответ сразу становится accepted/confirmed.
3. `unknown` остаётся pending/candidate.
4. Ручное назначение не перезаписывается и всегда может заменить решение ассистента.
5. UI показывает оставшееся число слоёв и происхождение автоматического назначения.
6. При ручном review панель выбора класса остаётся под sticky command bar, а список слоёв прокручивается под ней.

## Проверка

- API: 67 tests passed;
- web: 59 tests passed, TypeScript clean;
- production images API, semantic-worker и web собраны и запущены;
- sticky review bar использует измеренную ResizeObserver высоту command bar и отключается на узком mobile viewport;
- диагностический job `5da9e182-6a2c-46d0-9477-2ac6731e7f4b` завершил 2/2 без ошибок;
- `Подписи рамок` получил `not_applicable`, confirmed/accepted и assistant provenance;
- `Координатные кресты` остался unknown/candidate;
- словарные проверки в runtime: `теплосеть` и `теплотрасса` → heat pipeline; `трубопроводы` и `подземные коммуникации` → utility unknown;
- формы `навес`, `памятник`, `фонтан`, `ограда`, `вентилятор`, `спецсооружение`, `мост`, `павильон` в единственном и множественном числе → `structure.building`;
- `возд. линия/линии`, включая `возд линии телеграф`, → `utility.power.overhead`;
- `откос`, `откосы`, `подошва откоса` и `бровка откоса` → точный класс рельефа `terrain.slope_toe`;
- два ранее подтверждённых слоя не вошли в job.
- над списком слоёв доступен чекбокс выбора всех строк текущего фильтра; частичный выбор отражается промежуточным состоянием;
- CAD-файл с непустым набором полностью подтверждённых слоёв отмечается в дереве зелёной галкой в кружке.
- подтверждённые semantic assistant слои в режиме «Не разобраны» проигрывают ту же анимацию ухода вправо, что и при ручном назначении, до применения свежего снимка проекта.
