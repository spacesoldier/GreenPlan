# LibreDWG 0.14: диагностический DWG → DXF R2018

Дата прогона: 2026-09-23.

Команда для каждого файла: `dwg2dxf -v1 --as r2018 -y -o <temporary.dxf> <source.dwg>`. Полученный DXF измерялся и удалялся; полные stdout/stderr и метрики записаны в PostgreSQL как отдельная стадия `libredwg_dxf`. Каноническую выдачу ODA этот тест не заменяет.

Технический успех означает только `exit code = 0` и наличие непустого DXF. Он не означает отсутствие потерь. В логе встречаются, например:

- `TODO TABLESTYLE r2010+ missing fields`;
- `Unhandled Class object ...` для AEC-объектов;
- `Unstable Class object ...` для TABLESTYLE, MATERIAL, MLEADERSTYLE и других классов.

Самый шумный исходник — `20. Макеева С. ул/.../ИП_Макеева С. ул.dwg`: 102 616 диагностических строк.

## Решение для архитектуры

ODA остаётся основным DWG → DXF-конвертером. LibreDWG 0.14 используется как независимый reader и диагностический экспортёр. Для утверждения «без потерь» недостаточно успешного кода возврата обоих инструментов: нужны сравнение сущностей/слоёв, extents, block references, proxy/AEC-объектов и визуальный diff контрольных листов.
