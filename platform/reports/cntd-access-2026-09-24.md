# Диагностика доступа к docs.cntd.ru

Дата и время проверки: 2026-09-24 20:40–20:43 Asia/Tbilisi (19:40–19:43 Europe/Moscow).

## Проверенные адреса

```text
user URL:       https://docs.cntd.ru/document/5200163
current SP 42:  https://docs.cntd.ru/document/456054209
titles example: https://docs.cntd.ru/document/456054209/titles/8PO0M3
```

`5200163` относится к СНиП 2.07.01-89. По публичному индексу КОДЕКС актуализированный `СП 42.13330.2016` с изменениями № 1, 2, 3 и 4 находится под document id `456054209`.

Ориентир объёма: коммерческая карточка консолидированного печатного издания с изменениями № 1–4 указывает 140 страниц; базовая карточка стандарта указывает 90 страниц. HTML КОДЕКС не имеет собственного стабильного page count, поэтому фактическое число страниц фиксируется только после сохранения PDF/print-to-PDF и не выводится из этих ориентиров автоматически.

## Результат сетевой проверки

- DNS `docs.cntd.ru` разрешился в IPv4 `5.61.15.158`.
- `http://docs.cntd.ru/document/456054209` ответил `301 Moved Permanently` и перенаправил на HTTPS.
- TCP/HTTPS `docs.cntd.ru:443` не установился за 8 секунд; полный запрос завершился timeout через 30 секунд без HTTP headers.
- Такое же поведение получили корень сайта и `robots.txt`.
- Смена User-Agent и принудительный IPv4 результата не изменили.
- Web/search backend также получил timeout при live-open, но поисковый индекс возвращает cached titles и части текста.

Это указывает не на paywall-response страницы, а на недоступность HTTPS-маршрута именно из agent environment. Попытки обходить сетевое ограничение, авторизацию, CAPTCHA или правила провайдера не предпринимались.

## Разрешённый рабочий маршрут

1. В обычном браузере пользователя вечером открыть `document/456054209`.
2. Проверить заголовок, номер СП, список изменений и условия бесплатного доступа.
3. Использовать предоставленную функцию download; при её отсутствии и разрешённом чтении — print-to-PDF либо сохранение HTML с ресурсами.
4. Положить файл в `normatives/raw/`, не заменяя предыдущие редакции.
5. Запустить локальную регистрацию: MIME, размер, SHA-256, число страниц и текстовый слой/OCR.
6. Сверить, что изменения № 1–4 действительно вошли в сохранённый текст, и только после этого создавать rule candidates.

Публичные `/titles/{sectionId}` можно дополнительно сохранять как citation map, но нельзя считать заменой полного проверенного документа.
