# Локальный корпус нормативов

`manifest.yml` — реестр источников и статусов проверки. `raw/` предназначен только для законно доступных неизменяемых оригиналов; `extracted/` содержит производные результаты OCR/извлечения и не считается первоисточником.

Правила работы:

- не заменять файл по существующему пути при изменении SHA-256;
- не считать найденный в интернете PDF действующей редакцией без проверки;
- не коммитить документ, если его лицензия/право хранения не установлены;
- регистрировать даже link-only документы, но не извлекать из них правила до получения законной копии;
- публиковать правило только после сверки пункта/таблицы reviewer'ом.

Если документ доступен бесплатно только в вечернее окно, сохраняйте его вручную в `raw/` под новым неизменяемым именем и сразу заносите в manifest URL, timezone окна, способ получения, редакцию, размер и SHA-256. Не используйте скрипты для обхода авторизации, CAPTCHA или ограничений провайдера.
